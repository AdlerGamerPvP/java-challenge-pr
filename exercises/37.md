# Exercício 37 — Pontuação e Medalha

## 📋 Descrição

Leia a pontuação de um atleta (0–100) e exiba a medalha: **Ouro** (90–100), **Prata** (75–89), **Bronze** (60–74) ou **Sem medalha** (abaixo de 60).

**Exemplo de entrada:** `78`
**Exemplo de saída:** `Medalha de Prata!`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
