# Exercício 14 — IMC - Índice de Massa Corporal

## 📋 Descrição

Leia o peso (kg) e a altura (m), calcule o IMC e classifique: **Abaixo do peso** (<18,5), **Normal** (18,5–24,9), **Sobrepeso** (25–29,9), **Obesidade** (≥30).

**Exemplo de entrada:** `70` kg, `1.75` m
**Exemplo de saída:** `IMC: 22.86 - Normal.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
