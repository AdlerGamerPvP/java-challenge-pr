# Exercício 30 — Categoria de Produto

## 📋 Descrição

Leia o código de categoria (1-Alimentício, 2-Eletrônico, 3-Vestuário, 4-Limpeza) e exiba o nome e a alíquota de imposto (7%, 15%, 12%, 10%).

**Exemplo de entrada:** `2`
**Exemplo de saída:** `Eletrônico - Imposto: 15%`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `switch` para resolver este exercício.
