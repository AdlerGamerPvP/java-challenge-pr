# Exercício 06 — Calculadora Simples

## 📋 Descrição

Leia dois números e um operador (`+`, `-`, `*`, `/`). Realize a operação correspondente e exiba o resultado. Trate a divisão por zero.

**Exemplo de entrada:** `10`, `2`, `/`
**Exemplo de saída:** `Resultado: 5.0`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `switch` para resolver este exercício.

## 📁 Como entregar

Crie o arquivo `06.java` com a sua solução e faça o commit no seu fork.
