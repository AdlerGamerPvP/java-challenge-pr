# Exercício 24 — Tarifas de Energia Elétrica

## 📋 Descrição

Cobra energia conforme consumo mensal: até 100 kWh = R$0,40/kWh, 101–300 = R$0,65/kWh, acima de 300 = R$0,85/kWh. Leia o consumo e exiba o valor da conta.

**Exemplo de entrada:** `250`
**Exemplo de saída:** `Valor da conta: R$ 162.50`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
