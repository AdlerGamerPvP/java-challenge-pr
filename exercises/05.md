# Exercício 05 — Aprovado ou Reprovado

## 📋 Descrição

Leia a nota de um aluno (0 a 10). Se a nota for maior ou igual a 6, exiba **Aprovado**. Caso contrário, exiba **Reprovado**.

**Exemplo de entrada:** `7.5`
**Exemplo de saída:** `Aprovado.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
