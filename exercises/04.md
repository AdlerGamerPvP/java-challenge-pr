# Exercício 04 — Maior de Três Números

## 📋 Descrição

Leia três números inteiros e informe qual é o **maior** entre os três.

**Exemplo de entrada:** `4`, `9` e `2`
**Exemplo de saída:** `O maior número é 9.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.

## 📁 Como entregar

Crie o arquivo `04.java` com a sua solução e faça o commit no seu fork.
