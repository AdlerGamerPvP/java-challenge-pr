# Exercício 16 — Estação do Ano

## 📋 Descrição

Leia um mês (1–12) e exiba a **estação do ano** no hemisfério sul: Verão (dez–fev), Outono (mar–mai), Inverno (jun–ago), Primavera (set–nov).

**Exemplo de entrada:** `7`
**Exemplo de saída:** `Inverno.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `switch` para resolver este exercício.

Crie o arquivo `16.java` com a sua solução e faça o commit no seu fork.
