# Exercício 12 — Mês do Ano

## 📋 Descrição

Leia um número de 1 a 12 e exiba o **nome do mês** correspondente usando `switch`. Exiba mensagem de erro para valores inválidos.

**Exemplo de entrada:** `7`
**Exemplo de saída:** `Julho.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `switch` para resolver este exercício.

## 📁 Como entregar

Crie o arquivo `12.java` com a sua solução e faça o commit no seu fork.
