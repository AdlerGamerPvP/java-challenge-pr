# Exercício 07 — Classificação de Triângulo

## 📋 Descrição

Leia os três lados de um triângulo e classifique-o como **Equilátero** (três lados iguais), **Isósceles** (dois lados iguais) ou **Escaleno** (todos diferentes). Verifique antes se os lados formam um triângulo válido.

**Exemplo de entrada:** `3`, `3`, `3`
**Exemplo de saída:** `Triângulo Equilátero.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
