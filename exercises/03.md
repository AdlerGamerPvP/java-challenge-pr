# Exercício 03 — Maior de Dois Números

## 📋 Descrição

Leia dois números inteiros e informe qual deles é o **maior**. Se forem iguais, informe isso ao usuário.

**Exemplo de entrada:** `8` e `5`
**Exemplo de saída:** `O maior número é 8.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.

## 📁 Como entregar

Crie o arquivo `03.java` com a sua solução e faça o commit no seu fork.
