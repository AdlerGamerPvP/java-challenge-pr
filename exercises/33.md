# Exercício 33 — Faixa de Renda e Imposto

## 📋 Descrição

Leia o salário anual e calcule o IR: isento (até R$24.000), 7,5% (R$24.001–33.919), 15% (R$33.920–45.012), 22,5% (R$45.013–55.976), 27,5% (acima de R$55.976).

**Exemplo de entrada:** `40000`
**Exemplo de saída:** `Faixa: 15% | Imposto: R$ 6000.00`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
