# Exercício 31 — Validade de Data Simples

## 📋 Descrição

Leia dia, mês e ano. Verifique se a data é **válida**, considerando meses com 28, 29, 30 ou 31 dias e anos bissextos.

**Exemplo de entrada:** `29`, `02`, `2023`
**Exemplo de saída:** `Data inválida.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.

Crie o arquivo `31.java` com a sua solução e faça o commit no seu fork.
