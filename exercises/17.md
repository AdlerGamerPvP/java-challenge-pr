# Exercício 17 — Tipo de Veículo

## 📋 Descrição

Leia o número de rodas de um veículo e classifique: 2 = **Moto**, 4 = **Carro**, 6 ou mais = **Caminhão**, outros = **Desconhecido**.

**Exemplo de entrada:** `4`
**Exemplo de saída:** `Carro.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
