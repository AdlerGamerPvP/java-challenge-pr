# Exercício 34 — Classificação de Filmes por Faixa Etária

## 📋 Descrição

Leia a idade do espectador e a classificação do filme (Livre, 10, 12, 14, 16 ou 18 anos). Informe se a pessoa **pode** ou **não pode** assistir.

**Exemplo de entrada:** Idade `15`, classificação `16`
**Exemplo de saída:** `Não permitido: requer 16 anos ou mais.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.

## 📁 Como entregar

Crie o arquivo `34.java` com a sua solução e faça o commit no seu fork.
