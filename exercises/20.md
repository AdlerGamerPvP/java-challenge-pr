# Exercício 20 — Validação de Senha Simples

## 📋 Descrição

Leia uma senha digitada pelo usuário. Se for igual a `Java2024`, exiba **Acesso liberado**. Caso contrário, exiba **Senha incorreta**.

**Exemplo de entrada:** `Java2024`
**Exemplo de saída:** `Acesso liberado.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
