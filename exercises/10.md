# Exercício 10 — Desconto por Valor de Compra

## 📋 Descrição

Uma loja oferece desconto conforme o valor da compra: abaixo de R$50 sem desconto, de R$50 a R$99,99 desconto de 10%, R$100 ou mais desconto de 20%. Leia o valor e exiba o valor final.

**Exemplo de entrada:** `120.00`
**Exemplo de saída:** `Valor com desconto: R$ 96.00`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
