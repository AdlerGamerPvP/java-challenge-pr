# Exercício 13 — Nota e Conceito

## 📋 Descrição

Leia a nota de um aluno e exiba o **conceito**: A (9–10), B (7–8,9), C (5–6,9), D (3–4,9), F (abaixo de 3).

**Exemplo de entrada:** `8.0`
**Exemplo de saída:** `Conceito: B`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
