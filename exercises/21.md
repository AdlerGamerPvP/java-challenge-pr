# Exercício 21 — Tipo de Triângulo pelos Ângulos

## 📋 Descrição

Leia três ângulos internos. Verifique se são válidos (soma = 180°) e classifique: **Acutângulo** (todos < 90°), **Retângulo** (um = 90°) ou **Obtusângulo** (um > 90°).

**Exemplo de entrada:** `90`, `45`, `45`
**Exemplo de saída:** `Triângulo Retângulo.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
