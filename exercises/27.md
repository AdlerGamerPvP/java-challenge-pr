# Exercício 27 — Tipo Sanguíneo e Doação

## 📋 Descrição

Leia um tipo sanguíneo (A, B, AB ou O) e o fator Rh (+ ou -). Informe de quais tipos pode **receber** e para quais pode **doar**.

**Exemplo de entrada:** `O-`
**Exemplo de saída:** `Pode receber de: O-. Pode doar para: todos.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `switch` para resolver este exercício.
