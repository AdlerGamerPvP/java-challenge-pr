# Exercício 29 — Calculadora de Gorjeta

## 📋 Descrição

Leia o valor de uma conta e o nível de satisfação (1-Ruim, 2-Regular, 3-Bom, 4-Excelente). Gorjeta: Ruim=0%, Regular=5%, Bom=10%, Excelente=15%. Exiba a gorjeta e o total.

**Exemplo de entrada:** Conta `80.00`, satisfação `3`
**Exemplo de saída:** `Gorjeta: R$ 8.00 | Total: R$ 88.00`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `switch` para resolver este exercício.
