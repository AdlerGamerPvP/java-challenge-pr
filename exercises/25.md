# Exercício 25 — Jogo Pedra, Papel e Tesoura

## 📋 Descrição

Leia as jogadas de dois jogadores e determine o **vencedor** ou **empate**. Regras: pedra ganha de tesoura, tesoura ganha de papel, papel ganha de pedra.

**Exemplo de entrada:** Jogador 1: `pedra`, Jogador 2: `tesoura`
**Exemplo de saída:** `Jogador 1 venceu!`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
