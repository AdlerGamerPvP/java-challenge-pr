# Exercício 23 — Classificação de Temperatura

## 📋 Descrição

Leia a temperatura em Celsius e classifique: **Muito frio** (<10°), **Frio** (10–19°), **Agradável** (20–25°), **Quente** (26–34°), **Muito quente** (≥35°).

**Exemplo de entrada:** `22`
**Exemplo de saída:** `Temperatura agradável.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
