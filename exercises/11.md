# Exercício 11 — Dia da Semana

## 📋 Descrição

Leia um número de 1 a 7 e exiba o **dia da semana** correspondente usando `switch`. Exiba mensagem de erro para valores inválidos.

**Exemplo de entrada:** `3`
**Exemplo de saída:** `Quarta-feira.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `switch` para resolver este exercício.
