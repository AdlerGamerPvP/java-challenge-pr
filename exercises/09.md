# Exercício 09 — Categoria por Idade

## 📋 Descrição

Leia a idade de uma pessoa e classifique-a em: **Bebê** (0–2), **Criança** (3–12), **Adolescente** (13–17), **Adulto** (18–59) ou **Idoso** (60+).

**Exemplo de entrada:** `25`
**Exemplo de saída:** `Adulto.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.

Crie o arquivo `09.java` com a sua solução e faça o commit no seu fork.
