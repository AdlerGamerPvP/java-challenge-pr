# Exercício 02 — Positivo, Negativo ou Zero

## 📋 Descrição

Leia um número real e informe se ele é **positivo**, **negativo** ou **zero**.

**Exemplo de entrada:** `-3.5`
**Exemplo de saída:** `O número -3.5 é negativo.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
