# Exercício 18 — Nível de Combustível

## 📋 Descrição

Leia o nível de combustível em percentual (0–100). Exiba: **Tanque cheio** (100%), **Nível ok** (30–99%), **Atenção: abastecer em breve** (10–29%) ou **Nível crítico!** (abaixo de 10%).

**Exemplo de entrada:** `15`
**Exemplo de saída:** `Atenção: abastecer em breve.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
