# Exercício 38 — Verificação de Intervalo

## 📋 Descrição

Leia um valor e dois limites (mínimo e máximo). Informe se o valor está **dentro do intervalo** (inclusivo), **abaixo do mínimo** ou **acima do máximo**.

**Exemplo de entrada:** Valor `15`, mínimo `10`, máximo `20`
**Exemplo de saída:** `O valor 15 está dentro do intervalo [10, 20].`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
