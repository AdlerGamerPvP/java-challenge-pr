# Exercício 26 — Nível de Experiência de Jogador

## 📋 Descrição

Leia a pontuação de um jogador e classifique: **Novato** (0–999), **Iniciante** (1000–4999), **Intermediário** (5000–9999), **Avançado** (10000–24999), **Mestre** (25000+).

**Exemplo de entrada:** `12000`
**Exemplo de saída:** `Nível: Avançado.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
