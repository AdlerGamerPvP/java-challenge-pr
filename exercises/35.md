# Exercício 35 — Resultado de Operação Bancária

## 📋 Descrição

Leia o tipo de operação (1-Depósito, 2-Saque, 3-Transferência), o saldo atual e o valor. Para saque e transferência, verifique saldo suficiente. Exiba o saldo final.

**Exemplo de entrada:** Operação `2`, saldo `500.00`, valor `200.00`
**Exemplo de saída:** `Saque realizado. Saldo atual: R$ 300.00`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `switch` para resolver este exercício.

Crie o arquivo `35.java` com a sua solução e faça o commit no seu fork.
