# Exercício 28 — Placar de Futebol

## 📋 Descrição

Leia o placar de um jogo (gols do time A e gols do time B) e informe se o **Time A venceu**, o **Time B venceu** ou houve **Empate**.

**Exemplo de entrada:** Time A: `2`, Time B: `1`
**Exemplo de saída:** `Time A venceu!`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.

Crie o arquivo `28.java` com a sua solução e faça o commit no seu fork.
