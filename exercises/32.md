# Exercício 32 — Tipo de Conta Bancária

## 📋 Descrição

Leia o tipo de conta (1-Corrente, 2-Poupança, 3-Salário) e o saldo. Informe o tipo, se está positivo/zerado/negativo e, se corrente negativo, avise sobre o cheque especial.

**Exemplo de entrada:** Tipo `1`, saldo `-200.00`
**Exemplo de saída:** `Conta Corrente | Saldo negativo | Cheque especial ativo.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `switch` para resolver este exercício.
