# Exercício 22 — Maior e Menor entre Quatro Números

## 📋 Descrição

Leia quatro números inteiros e informe o **maior** e o **menor** entre eles.

**Exemplo de entrada:** `3`, `7`, `1`, `5`
**Exemplo de saída:** `Maior: 7 | Menor: 1`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.
