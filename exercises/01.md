# Exercício 01 — Par ou Ímpar

## 📋 Descrição

Leia um número inteiro digitado pelo usuário e informe se ele é **par** ou **ímpar**.

**Exemplo de entrada:** `7`
**Exemplo de saída:** `O número 7 é ímpar.`

## 📥 Entrada

Use `Scanner` para ler os dados do usuário via terminal.

## 📤 Saída

Exiba o resultado no terminal usando `System.out.println()`.

## 💡 Dica

Utilize `if/else` para resolver este exercício.

## 📁 Como entregar

Crie o arquivo `01.java` com a sua solução e faça o commit no seu fork.
